# دیدبان — Didban 👁️

**مرکز فرماندهی، عیب‌یابی و پایش جامع سرورهای لینوکسی. ساده، فوق‌العاده سبک — و بهت می‌گوید دیشب «چه چیزی» CPU را خورد.**

## چرا دیدبان؟

هر ادمین سروری این سؤال ساعت ۲ نصفه‌شب را می‌شناسد: **«دیشب CPU صد درصد بود — چی بود؟»** دیدبان جوابش را می‌دهد. یک ایجنت سبک و بهینه‌ی Go روی هر سرور اجرا می‌شود، اسپایک‌های منابع را **همراه با پروسه‌های مقصر** ثبت می‌کند، هشدارهای آنی به **تلگرام، دیسکورد و وب‌هوک** می‌فرستد، **صفحه وضعیت عمومی HTML تحت وب** ارائه می‌دهد، **پایش پایداری سرویس‌ها و سایت‌ها (مشابه Uptime Kuma با نوارهای ضربان Heartbeat)** را انجام می‌دهد، **کانتینرهای داکر را پایش و مدیریت** می‌کند، **پورت‌های باز و سوکت‌های فعال** را نشان می‌دهد، امکان **بستن پروسه‌های مخرب با ۱ کلیک** را می‌دهد، و همراه با یک **جعبه‌ابزار همه‌فن‌حریف شبکه و DevOps** (عیب‌یابی فیلترینگ و DPI، مدیریت کلودفلر، بازرس SSL، پورت‌اسکنر، اطلاعات IP و GeoIP، گاوصندوق رمزنگاری‌شده، وب‌سرور داخلی و ابزارهای توسعه‌دهنده) عرضه می‌شود.

- 🚀 **مرکز تانل بین دو سرور (Iran Node ➔ Foreign Node)** — مدیریت و راه‌اندازی آسان و خودکار تانل‌های معکوس، سوکت خام، پکت‌های پینگ و IP Spoofing بین سرور ایران و خارج با پشتیبانی کامل از **BackPack 🎒 (توسعه‌یافته توسط AminMGMT)**، **Paqet (سوکت خام و KCP)**، **Narnia (تونل پنهان ICMP Ping با ChaCha20)**، **Spoof Tunnel (جعل دوطرفه IP مبدا با Reed-Solomon FEC)**، **Backhaul**، **Rathole**، **GOST**، **Chisel**، **FRP** و **IPTables**؛ همراه با تولید خودکار اسکریپت‌های تک‌خطی نصاب، سرویس‌های Systemd و Docker Compose
- 📊 **متریک زنده سرور** — CPU (شامل %steal!)، رم/سواپ، دیسک، ترافیک شبکه، لود، آپتایم
- 🕵️ **تحلیل اسپایک‌ها** — هر اسپایک CPU/رم سمت سرور ثبت می‌شود همراه با **پروسه‌های مقصر** — حتی وقتی گوشی‌ات خاموش است
- 🐳 **پایش و مدیریت کانتینرهای داکر (Docker)** — اتصال مستقیم و بدون وابستگی به `/var/run/docker.sock`، پایش سلامت و وضعیت کانتینرها، هشدار کرش/داون شدن کانتینرها، و ری‌استارت/استاپ از راه دور با ۱ کلیک
- ⏱️ **موتور پایش آپ‌تایم (مشابه Uptime Kuma)** — مانیتورینگ HTTP(S)، پورت‌های TCP (دیتابیس‌ها و سرویس‌ها)، پینگ، کلمات کلیدی و سرتیفیکیت SSL با نوارهای ۳۰ تایی ضربان قلب و ثبت حوادث قطعی
- 🛡️ **عیب‌یابی فیلترینگ و بازرس دستکاری بسته (DPI)** — تست و تفکیک قطعی لایه ۳/۴، تزریق پکت‌های مخرب TCP RST و دستکاری هندشیک TLS/SNI
- 📄 **صفحه وضعیت وب (Public Status Page)** — صفحه شیک وضعیت سلامت سرور در آدرس `/status`
- ✈️ **هشدارهای چندکاناله** — ارسال پیام به **تلگرام**، **دیسکورد (Webhooks)** و **وب‌هوک سفارشی**
- 👂 **پورت‌های باز و اتصالات فعال سرور** — مشاهده زنده پورت‌های در حال شنود و سوکت‌های متصل به همراه نام پروسه و PID
- 🛑 **مدیریت و بستن پروسه‌ها** — جستجو، بررسی و بستن امن پروسه‌ها (SIGTERM / SIGKILL) از داخل اپلیکیشن یا API
- ☁️ **مدیریت Cloudflare DNS** — مدیریت دامنه‌ها و رکوردهای DNS (A, AAAA, CNAME, TXT, MX)، تغییر وضعیت پروکسی ابری و تنظیم TTL
- 🌐 **تست دسترسی جهانی (Check-Host)** — بررسی آنلاین وضعیت سرور (Ping / HTTP / TCP / DNS) از بیش از ۲۰ نود در جهان (آلمان، آمریکا، ایران، فرانسه و...)
- 🛰️ **ابزارهای شبکه** — پورت‌اسکنر چندنخی، بازرس سرتیفیکیت SSL (شمارش معکوس انقضا، SANها، زنجیره)، استعلام GeoIP و پینگ‌تستر
- 🔐 **گاوصندوق رمزنگاری‌شده** — ذخیره امن یادداشت‌ها و پسوردها با رمزنگاری پیشرفته‌ی AES-256-GCM و امکان پشتیبان‌گیری/بازیابی کامل
- 📡 **وب‌سرور اشتراک فایل و QR Code** — اشتراک‌گذاری سریع فایل و متن روی شبکه محلی و Wi-Fi همراه با بارکد QR
- 🛠️ **جعبه‌ابزار توسعه‌دهنده (String Lab)** — ابزارهای Base64، فرمت و فشرده‌سازی JSON، محاسبه‌گر ساب‌نت/CIDR، رمزگشای JWT، هش‌ها و تولیدکننده پسورد/UUID
- 📱 **اپ اندروید** — دوزبانه (فارسی/انگلیسی)، تم تیره Obsidian، نصب خودکار ۱-کلیکه با SSH
- 🔐 **امن به‌صورت پیش‌فرض** — HTTPS با cert خوداموقع + توکن؛ اپ fingerprint سرتیفیکیت را پین می‌کند (مثل SSH)
- 🪶 **سبک** — یک باینری استاتیک Go (~۸ مگابایت)، بدون هیچ وابستگی جانبی، ~۱۰ مگ رم

## نصب (یک دستور برای هر سرور)

روی هر سرور اجرا کن (اوبونتو/دبیان، هر معماری — amd64/arm64/arm/386):

```bash
curl -fsSL https://raw.githubusercontent.com/Mohammad1724/didban/main/agent/install.sh -o didban-install.sh
sudo bash didban-install.sh
```

اگه فایروال داری، پورت رو باز کن:

```bash
sudo ufw allow 8686
```

## مرکز مدیریت تانل بین دو سرور (Iran-Kharej Dual Node)

دیدبان به شما امکان می‌دهد تا تانل‌های ترافیکی بین سرور ایران (Bridge / Relay) و سرور خارج (Upstream / Client) را با محبوب‌ترین و مدرن‌ترین هسته‌های ضد فیلترینگ مدیریت و پایش کنید:

1. **BackPack 🎒 (by AminMGMT)**: موتور تانلینگ نسل جدید Go با رمزنگاری Noise NNpsk0 (بدون فینگرپرینت TLS)، دور زدن conntrack کرنل لینوکس (PCK)، گیمینگ کم‌تاخیر KCP+FEC، شبیه‌سازی فینگرپرینت کروم و سایت استتار (WSS Decoy)، تونل روی پکت‌های پینگ (xDi) و پریست‌های Turbo و Gaming.
2. **Paqet (by behzadea12 / hanselime)**: تانل پرسرعت بر بستر Raw Socket و پروتکل KCP با قابلیت دور زدن فیلترهای سخت‌گیرانه لایه ۴ و DPI، مجهز به مدهای کاری Fast/Turbo و رمزنگاری‌های AES-GCM و ChaCha20-Poly1305.
3. **Narnia (by Dnt3e)**: تانل نامرئی لایه ۳ پنهان‌شده در دل پکت‌های معمولی ICMP Ping با رمزنگاری نفوذناپذیر ChaCha20، بازسازی هوشمند پکت‌ها (بدون تکه‌تکه‌شدگی Fragmentation) و عملکرد پایدار مشابه کابل مستقیم حتی در زمان اختلالات شدید اینترنت.
4. **Spoof Tunnel (by ParsaKSH & variants)**: تکنیک پیشرفته‌ی جعل دوطرفه IP مبدا (Mutual IP Spoofing) در لایه ۳ و ۴ با سوکت خام، لایه اختصاصی تضمین تحویل پکت‌ها (Reliability Layer) و سیستم بازیابی خطای Reed-Solomon FEC.
5. **Backhaul**: تانل معکوس پایدار مبتنی بر WebSocket و TCP با پشتیبانی از مالتی‌پورت، اتصال خودکار پس از قطعی، و عملکرد عالی روی اینترنت ملی ایران.
6. **Rathole**: پیاده‌سازی به زبان Rust با امنیت بالا با بهره‌گیری از Noise Protocol و مصرف بسیار ناچیز حافظه رم (< ۱۰ مگابایت).
7. **GOST (GO Simple Tunnel)**: هسته رله چندمنظوره با قابلیت‌های قدرتمند فورواردینگ بر بستر پروتکل‌های TLS ،WebSocket ،gRPC ،TCPMux و UDP.
8. **Chisel**: تانل مبتنی بر HTTP/WS با رمزنگاری سرتاسری و عبور مطمئن از فایروال‌های سخت‌گیر و DPI.
9. **FRP (Fast Reverse Proxy)**: ریورس پروکسی سریع و تست‌شده برای فوروارد پورت‌های TCP و UDP به شبکه داخلی یا خارج.
10. **IPTables / Port Forward**: فوروارد مستقیم در سطح هسته لینوکس بدون سربار برنامه جانبی.

برای هر تانل:
- **دستور نصاب ۱-کلیکه برای سرور ایران و خارج**: دستورات را کپی کرده یا با ۱ کلیک نصب کنید.
- **کانفیگ آماده و Docker-Compose**: فایل‌های `docker-compose.yml` و کانفیگ‌های `toml`/`yaml` جهت اجرای بدون دردسر.
- **تست پینگ و زنده بودن تانل**: تست زمان پاسخگویی (Latency) و پایش مداوم اتصال پورت‌های تانل.

## صفحه وضعیت عمومی (Status Page)

برای مشاهده صفحه وب وضعیت سرور، آدرس زیر را در مرورگر باز کنید:
`https://IP_سرور:8686/status`

## تنظیم هشدارها (تلگرام، دیسکورد و وب‌هوک)

در فایل `/etc/didban/agent.conf` مقادیر را تنظیم کنید:

```bash
# در فایل /etc/didban/agent.conf
DIDBAN_TG_TOKEN="123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
DIDBAN_TG_CHAT_ID="-100123456789"
# وب‌هوک دیسکورد:
# DIDBAN_DISCORD_WEBHOOK="https://discord.com/api/webhooks/..."
# وب‌هوک سفارشی:
# DIDBAN_WEBHOOK_URL="https://mywebhook.site/endpoint"
# پروکسی اختیاری تلگرام:
# DIDBAN_TG_PROXY="socks5://127.0.0.1:1080"
```

سپس سرویس را ری‌استارت کنید:
```bash
sudo systemctl restart didban-agent
```

تست ارسال هشدار:
```bash
curl -sk -X POST https://IP_سرور:8686/api/alerts/test -H "Authorization: Bearer توکن"
```

## API

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/health` | زنده بودن و وضعیت هشدارها (بدون توکن) |
| `GET` | `/status` | صفحه وضعیت عمومی سرور تحت وب |
| `GET` | `/api/metrics` | CPU (شامل %steal)، رم، سواپ، دیسک، شبکه، لود، آپتایم |
| `GET` | `/api/docker/containers` | لیست کانتینرهای داکر، سلامت، وضعیت، ایمیج و پورت‌ها |
| `POST` | `/api/docker/restart` | ری‌استارت کانتینر داکر (`{"id": "container_id_or_name"}`) |
| `POST` | `/api/docker/stop` | متوقف کردن کانتینر داکر (`{"id": "container_id_or_name"}`) |
| `GET` | `/api/processes` | ۲۵ پروسه‌ی برتر بر اساس CPU |
| `GET` | `/api/network/sockets` | پورت‌های باز و سوکت‌های فعال متصل‌شده همراه با PID و نام پروسه |
| `POST` | `/api/processes/kill` | خاتمه دادن امن به پروسه (`{"pid": 1234, "signal": "SIGTERM"}`) |
| `POST` | `/api/alerts/test` | ارسال پیام تست به تلگرام، دیسکورد و وب‌هوک |
| `GET` | `/api/events?limit=50` | رویدادهای اسپایک و کرش کانتینرها با پروسه‌های مقصر |
| `GET` | `/api/history?hours=24` | تاریخچه‌ی دقیقه‌ای برای نمودار |
